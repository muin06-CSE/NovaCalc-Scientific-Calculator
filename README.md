# NovaCalc – Scientific Calculator

A simple scientific calculator application developed using Python and Tkinter.

## Features
- Basic arithmetic operations
- Trigonometric functions (sin, cos, tan)
- Square root
- Logarithm and natural logarithm
- Power operations
- Pi and Euler's number
- Error handling

## Technologies Used
- Python
- Tkinter
- Math Library

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Run the following command:

```bash
python nova_calc.py
```
